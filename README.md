# ProjetoScienza - A Batalha Icônica da Estação Maria Azul

<a href="https://camp-studio.itch.io/a-batlha-icnica-da-estao-maria-azul"> Link da página do Itch.io com a build do jogo</a>.

Jogo desenvolvido para a primeira edição da Scienza Game Jam

"Como seu vocabulário muda a sua relação com o mundo?"

A Batalha Icônica da Estação Maria Azul é um jogo 2D sobre batalhas de rima, vistas através da lente da semiótica. Explore a estação, colete referências e derrote seu oponente.

Idioma do jogo: português brasileiro
